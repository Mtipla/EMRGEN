| HU | Criterio ID | Criterio de Aceptación Verificable |
| --- | --- | --- |
| HU-01 | CA-01.1 | Formato de correo electrónico válido y no repetido en la BD. |
| HU-01 | CA-01.2 | Contraseña con hash de seguridad (BCrypt/Argon2) antes de persistir. |
| HU-02 | CA-02.1 | Retorno de token JWT válido con tiempo de expiración (p. ej., 24 hrs). |
| HU-03 | CA-03.1 | Validación de formato numérico de teléfono. |
| HU-03 | CA-03.2 | Bloqueo al intentar ingresar un 6º contacto (Límite estricto = 5). |
| HU-04 | CA-04.1 | Confirmación antes de eliminar; no permite dejar la lista en 0 contactos. |
| HU-05 | CA-05.1 | Texto de mensaje limitado a un máximo de 160 caracteres. |
| HU-06 | CA-06.1 | Exige presionar continuamente por 2 segundos para gatillar el evento SOS. |
| HU-07 | CA-07.1 | Obtención de latitud/longitud con fallback a última posición guardada si falla el GPS. |
| HU-08 | CA-08.1 | Notificación enviada exitosamente a la totalidad de contactos de la lista. |
| HU-09 | CA-09.1 | Restricción de máximo 5 dependientes por cuenta principal. |
| HU-10 | CA-10.1 | PIN numérico exacto de 4 dígitos. Tres intentos fallidos bloquean la acción por 5 min. |
| HU-11 | CA-11.1 | Campos de salud almacenados con cifrado en reposo AES-256. |
| HU-12 | CA-12.1 | Revocación automática de visibilidad médica al cambiar estado a "Emergencia Finalizada". |
