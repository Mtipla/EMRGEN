# Sprints Planning de la Fase 2
## Sprint 5: Preparación inicial del proyecto
Periodo: 21 al 25 de septiembre de 2026
Sprint Goal: Preparar el ambiente y la estructura técnica inicial del proyecto, incluyendo la conexión con la base de datos y el registro de usuario.
Hito académico: revisión del avance y recepción de retroalimentación durante la clase semanal con el profesor. El día jueves 24 a las 1:40.
Tareas del Sprint Backlog
Diseñar la estructura de datos necesaria para el registro de usuario.
Implementar el formulario/proceso de registro con nombre, correo y contraseña.
Implementación de correo electrónico y contraseña válidos.
Realizar el levantamiento inicial de la base de datos y revisar la estructura necesaria para el proyecto.
Configurar y realizar la conexión inicial con la base de datos.
Verificar la comunicación entre el proyecto y la base de datos mediante una prueba de conexión.
Verificar las versiones de las tecnologías, dependencias y herramientas utilizadas para evitar incompatibilidades.
Preparar y configurar el ambiente de desarrollo del proyecto.
Crear la estructura inicial del proyecto y configurar su organización base.
Seguimiento y evidencia esperada
Daily Scrum: 21, 22, 23, 24 y 25 de septiembre.
Evidencia esperada: Primera iteración del proyecto, Base de datos, Sistema de registro de usuario,
Cierre: Sprint Review y Sprint Retrospective
Resultado en Trello: objetivo cumplido 3/3 y tarjetas del Sprint completadas.
