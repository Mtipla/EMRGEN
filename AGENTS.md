# Instrucciones del proyecto

## Protección de init.sql

Por instrucción expresa del usuario, ningún archivo `init.sql` de este proyecto se debe modificar de ninguna forma.

- No editarlo, sobrescribirlo, regenerarlo, reformatearlo ni modificarlo mediante scripts, herramientas o procesos automáticos.
- Si una tarea requiere un cambio en `init.sql`, presentar únicamente sugerencias al usuario, sin aplicarlas al archivo.
- Esta regla se aplica a todas las tareas y futuras sesiones de trabajo sobre este proyecto.
